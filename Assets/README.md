# Application icon

`AppIcon.png` is the generated master asset, with transparent pixels outside the rounded square. The build derives the macOS `.icns` sizes and browser icon from it.

Generated with the built-in `imagegen` tool. Visual prompt: a minimal ivory desktop-monitor outline with a mint cursor overlapping its lower-right edge, on a deep graphite rounded square; no text, a strong silhouette and restrained dimensionality. A second edit removed the exterior white canvas while preserving the design.
